## 模块概览

MM (Memory Management) 模块实现了基于 RISC-V SV39 的分页式虚拟内存管理系统，包括：

- 物理页帧分配器
- 内核堆分配器
- 三级页表机制
- 虚拟地址空间抽象
- 类型安全的地址系统

每个任务或进程都有一个 `MemorySet` 来管理其虚拟内存空间。

## 各文件功能详解

### 1. `mod.rs` - 模块入口

**职责**：统一模块接口，提供初始化函数

**主要函数**：

```rust
pub fn init() {
    heap_allocator::init_heap();              // 初始化内核堆
    frame_allocator::init_frame_allocator();  // 初始化页帧分配器
    KERNEL_SPACE.exclusive_access().activate(); // 激活内核地址空间
}
```

**导出接口**：
- `PhysAddr`, `VirtAddr`, `PhysPageNum`, `VirtPageNum` - 地址类型
- `frame_alloc`, `FrameTracker` - 页帧分配
- `MemorySet`, `MapPermission`, `KERNEL_SPACE` - 地址空间管理
- `PageTableEntry`, `translated_byte_buffer` - 页表相关

---

### 2. `address.rs` - 地址类型系统

**职责**：定义类型安全的地址和页号抽象

#### 核心类型

| 类型 | 位宽 | 说明 |
|------|------|------|
| `VirtAddr` | 39位 | 虚拟地址 (SV39) |
| `PhysAddr` | 56位 | 物理地址 |
| `VirtPageNum` | 27位 | 虚拟页号 |
| `PhysPageNum` | 44位 | 物理页号 |

#### 关键方法

**地址类型**：
```rust
// 地址 → 页号
VirtAddr::floor()  // 向下取整
VirtAddr::ceil()   // 向上取整
VirtAddr::page_offset()  // 获取页内偏移

// 页号 → 地址
VirtPageNum::into() → VirtAddr
```

**物理页号特殊方法**：
```rust
PhysPageNum::get_pte_array()   // 作为页表数组访问 [PageTableEntry; 512]
PhysPageNum::get_bytes_array() // 作为字节数组访问 [u8; 4096]
PhysPageNum::get_mut<T>()      // 作为泛型类型访问
```

**虚拟页号索引**：
```rust
VirtPageNum::indexes() → [usize; 3]  // 返回三级页表索引
// 例如：VPN = 0x12345 → [0x48, 0x1a2, 0x145]
```

#### 辅助类型

- `VPNRange`: 虚拟页号范围，支持迭代
- `SimpleRange<T>`: 通用范围类型
- `StepByOne`: 迭代器 trait

### 3. `heap_allocator.rs` - 内核堆分配器

**职责**：为内核提供动态内存分配（支持 `Vec`, `Box`, `String` 等）

#### 架构

```
Rust 标准库动态内存分配 (Box, Vec, String...)
            ↓
    #[global_allocator]
    HEAP_ALLOCATOR: LockedHeap
    (伙伴系统算法)
            ↓
    HEAP_SPACE: [u8; KERNEL_HEAP_SIZE]
    (静态分配在 .bss 段)
```

#### 关键组件

**全局分配器**：
```rust
#[global_allocator]
static HEAP_ALLOCATOR: LockedHeap = LockedHeap::empty();
```

**堆空间**：
```rust
static mut HEAP_SPACE: [u8; KERNEL_HEAP_SIZE] = [0; KERNEL_HEAP_SIZE];
```

**初始化**：
```rust
pub fn init_heap() {
    unsafe {
        HEAP_ALLOCATOR
            .lock()
            .init(HEAP_SPACE.as_ptr() as usize, KERNEL_HEAP_SIZE);
    }
}
```

**错误处理**：
```rust
#[alloc_error_handler]
pub fn handle_alloc_error(layout: core::alloc::Layout) -> ! {
    panic!("Heap allocation error, layout = {:?}", layout);
}
```

#### 特点

- **分配单位**：字节级（任意大小）
- **算法**：伙伴系统（Buddy System）
- **线程安全**：通过 `LockedHeap` 实现
- **固定大小**：启动时确定，不能扩展

### 4. `frame_allocator.rs` - 物理页帧分配器

**职责**：管理物理内存页帧（以 4KB 为单位）

#### 核心结构

**FrameTracker - RAII 守卫**：
```rust
pub struct FrameTracker {
    pub ppn: PhysPageNum,
}

impl FrameTracker {
    pub fn new(ppn: PhysPageNum) -> Self {
        // 1. 清零整个页面（安全性）
        let bytes_array = ppn.get_bytes_array();
        for i in bytes_array {
            *i = 0;
        }
        // 2. 返回 Tracker
        Self { ppn }
    }
}

impl Drop for FrameTracker {
    fn drop(&mut self) {
        frame_dealloc(self.ppn);  // 自动回收
    }
}
```

**StackFrameAllocator - 栈式分配器**：
```rust
pub struct StackFrameAllocator {
    current: usize,        // 当前分配位置
    end: usize,            // 可用内存结束位置
    recycled: Vec<usize>,  // 回收的页帧栈
}
```

#### 分配策略

```
frame_alloc():
    ├─ 优先从 recycled 栈弹出（复用）
    ├─ 若栈为空，从 [current, end) 分配新页
    └─ 返回 FrameTracker（RAII 管理）

frame_dealloc():
    └─ 将页帧推入 recycled 栈
```

#### RAII 自动资源管理

```rust
{
    let frame = frame_alloc().unwrap();  // 分配页帧，页面已清零
    // ... 使用页帧 ...
}  // frame 离开作用域，自动调用 Drop，页帧回收
```

#### 特点

- **分配单位**：4KB 物理页
- **算法**：栈式分配 + 回收栈
- **安全性**：分配时自动清零
- **自动管理**：通过 RAII 模式

### 5. `page_table.rs` - 页表管理

**职责**：实现 SV39 三级页表机制

#### 核心结构

**PTEFlags - 页表项标志**：
```rust
bitflags! {
    pub struct PTEFlags: u8 {
        const V = 1 << 0;  // Valid - 有效位
        const R = 1 << 1;  // Read - 可读
        const W = 1 << 2;  // Write - 可写
        const X = 1 << 3;  // Execute - 可执行
        const U = 1 << 4;  // User - 用户可访问
        const G = 1 << 5;  // Global - 全局映射
        const A = 1 << 6;  // Accessed - 已访问
        const D = 1 << 7;  // Dirty - 已修改
    }
}
```

**PageTableEntry - 页表项**：
```
┌──────────────────────────────────────────────────────┐
│           PageTableEntry.bits (64位)                  │
├──────────────────────────────────────────────────────┤
│  63-54   │   53-10 (44位)    │  9-8  │   7-0         │
│  Reserved│   PPN (物理页号)   │ RSW   │  Flags (标志) │
└──────────────────────────────────────────────────────┘
```

```rust
impl PageTableEntry {
    pub fn new(ppn: PhysPageNum, flags: PTEFlags) -> Self;
    pub fn ppn(&self) -> PhysPageNum;      // 提取物理页号
    pub fn flags(&self) -> PTEFlags;       // 提取标志位
    pub fn is_valid(&self) -> bool;        // 是否有效
    pub fn readable(&self) -> bool;
    pub fn writable(&self) -> bool;
    pub fn executable(&self) -> bool;
}
```

**PageTable - 页表**：
```rust
pub struct PageTable {
    root_ppn: PhysPageNum,          // 根页表物理页号
    frames: Vec<FrameTracker>,      // 管理所有页表页帧
}
```

#### 三级页表查找流程

```
VirtPageNum (27位)
    │
    ├─ [26:18] 一级索引 (9位, 0-511)
    ├─ [17:9]  二级索引 (9位, 0-511)
    └─ [8:0]   三级索引 (9位, 0-511)

find_pte(vpn):
    1. 从 root_ppn 开始
    2. 用一级索引在一级页表中查找 PTE
    3. 从 PTE 提取 ppn，指向二级页表
    4. 用二级索引在二级页表中查找 PTE
    5. 从 PTE 提取 ppn，指向三级页表
    6. 用三级索引在三级页表中查找 PTE（最终）
    7. 返回最终的 PageTableEntry
```

#### 主要方法

```rust
impl PageTable {
    pub fn new() -> Self;                    // 创建新页表
    pub fn from_token(satp: usize) -> Self;  // 从 SATP 重建
    
    pub fn map(&mut self, vpn, ppn, flags);  // 建立映射
    pub fn unmap(&mut self, vpn);            // 解除映射
    pub fn translate(&self, vpn) -> Option<PageTableEntry>;  // 地址翻译
    
    pub fn token(&self) -> usize;            // 生成 SATP 值
    
    fn find_pte(&self, vpn) -> Option<&mut PageTableEntry>;  // 查找页表项
    fn find_pte_create(&mut self, vpn) -> Option<&mut PageTableEntry>;  // 查找或创建
}
```

#### token() 和 SATP 寄存器

```rust
pub fn token(&self) -> usize {
    8usize << 60 | self.root_ppn.0
}

// SATP 寄存器格式：
// [63:60] MODE (8 = SV39)
// [59:44] ASID (地址空间标识符)
// [43:0]  PPN (根页表物理页号)
```

### 6. `memory_set.rs` - 地址空间抽象

**职责**：管理完整的虚拟地址空间（最高层抽象）

#### 核心结构

**MemorySet - 地址空间**：
```rust
pub struct MemorySet {
    page_table: PageTable,      // 该地址空间的页表
    areas: Vec<MapArea>,        // 多个内存区域
}
```

**MapArea - 内存区域**：
```rust
pub struct MapArea {
    vpn_range: VPNRange,                        // 虚拟页号范围
    data_frames: BTreeMap<VirtPageNum, FrameTracker>,  // 映射的物理页帧
    map_type: MapType,                          // 映射类型
    map_perm: MapPermission,                    // 权限
}
```

**MapType - 映射类型**：
```rust
pub enum MapType {
    Identical,  // 恒等映射 (VA == PA)，用于内核
    Framed,     // 帧映射 (VA != PA)，用于用户程序
}
```

**MapPermission - 映射权限**：
```rust
bitflags! {
    pub struct MapPermission: u8 {
        const R = 1 << 1;  // 可读
        const W = 1 << 2;  // 可写
        const X = 1 << 3;  // 可执行
        const U = 1 << 4;  // 用户态可访问
    }
}
```

#### 内核地址空间布局

```rust
KERNEL_SPACE 包含：
├─ .text 段      [stext, etext)      R+X, 恒等映射
├─ .rodata 段    [srodata, erodata)  R,   恒等映射
├─ .data 段      [sdata, edata)      R+W, 恒等映射
├─ .bss 段       [sbss, ebss)        R+W, 恒等映射
├─ 物理内存      [ekernel, MEMORY_END) R+W, 恒等映射
├─ MMIO 区域     (设备寄存器)         R+W, 恒等映射
└─ trampoline    (跳板页)            R+X, 恒等映射
```

#### 用户地址空间布局

```rust
用户进程 MemorySet 包含：
├─ ELF 段        (.text, .data 等)   R/W/X+U, 帧映射
├─ 用户栈        [stack_bottom, stack_top) R+W+U, 帧映射
│   └─ guard page (保护页，防止栈溢出)
├─ 堆区域        (用于 sbrk)         R+W+U, 帧映射
├─ TrapContext   [TRAP_CONTEXT, TRAMPOLINE) R+W, 帧映射
└─ trampoline    TRAMPOLINE 页       R+X, 恒等映射
```

#### 主要方法

**创建地址空间**：
```rust
impl MemorySet {
    pub fn new_bare() -> Self;              // 创建空地址空间
    pub fn new_kernel() -> Self;            // 创建内核地址空间
    pub fn from_elf(elf_data: &[u8]) -> (Self, usize, usize);  // 从 ELF 创建
}
```

**管理映射**：
```rust
pub fn push(&mut self, map_area: MapArea, data: Option<&[u8]>);
pub fn insert_framed_area(&mut self, start_va, end_va, permission);
pub fn shrink_to(&mut self, start: VirtAddr, new_end: VirtAddr) -> bool;
pub fn append_to(&mut self, start: VirtAddr, new_end: VirtAddr) -> bool;
```

**激活地址空间**：
```rust
pub fn activate(&self) {
    let satp = self.page_table.token();
    unsafe {
        satp::write(satp);       // 写入 SATP 寄存器
        asm!("sfence.vma");      // 刷新 TLB
    }
}
```

**地址翻译**：
```rust
pub fn translate(&self, vpn: VirtPageNum) -> Option<PageTableEntry>;
pub fn token(&self) -> usize;  // 返回 SATP 值
```

#### MapArea 详细操作

```rust
impl MapArea {
    pub fn new(start_va, end_va, map_type, map_perm) -> Self;
    
    pub fn map(&mut self, page_table: &mut PageTable) {
        // 为整个区域建立映射
        for vpn in self.vpn_range {
            self.map_one(page_table, vpn);
        }
    }
    
    pub fn map_one(&mut self, page_table: &mut PageTable, vpn: VirtPageNum) {
        let ppn = match self.map_type {
            MapType::Identical => PhysPageNum(vpn.0),
            MapType::Framed => {
                let frame = frame_alloc().unwrap();
                let ppn = frame.ppn;
                self.data_frames.insert(vpn, frame);  // 保存 FrameTracker
                ppn
            }
        };
        page_table.map(vpn, ppn, flags);
    }
    
    pub fn copy_data(&mut self, page_table: &PageTable, data: &[u8]) {
        // 将数据复制到映射的物理页帧中
    }
}
```

## 运行流程

### 1. 启动阶段

```
main.rs: rust_main()
    │
    ▼
mm::init()
    │
    ├─ 1. init_heap()
    │    │
    │    └─ 初始化 HEAP_SPACE
    │        设置全局分配器
    │        现在可以使用 Vec, Box 等
    │
    ├─ 2. init_frame_allocator()
    │    │
    │    └─ 设置可用物理内存范围
    │        [ekernel, MEMORY_END)
    │
    └─ 3. KERNEL_SPACE.activate()
         │
         ├─ 创建内核地址空间 (new_kernel)
         │   ├─ 映射 .text (R+X)
         │   ├─ 映射 .rodata (R)
         │   ├─ 映射 .data (R+W)
         │   ├─ 映射 .bss (R+W)
         │   ├─ 映射物理内存 (R+W)
         │   ├─ 映射 MMIO (R+W)
         │   └─ 映射 trampoline (R+X)
         │
         └─ 激活 (activate)
             ├─ 写入 SATP 寄存器
             └─ 刷新 TLB (sfence.vma)
                 │
                 ▼
         🎉 内核现在运行在虚拟地址空间！
```

### 2. 用户进程创建

```
加载 ELF 文件
    │
    ▼
MemorySet::from_elf(elf_data)
    │
    ├─ 1. 创建空的 MemorySet
    │
    ├─ 2. 映射 trampoline
    │
    ├─ 3. 解析 ELF program headers
    │    │
    │    └─ 对每个 LOAD 段：
    │        ├─ 创建 MapArea (Framed, R/W/X+U)
    │        ├─ 分配物理页帧
    │        ├─ 建立页表映射
    │        └─ 复制段数据到页帧
    │
    ├─ 4. 创建用户栈
    │    ├─ 添加 guard page (防止栈溢出)
    │    └─ 映射栈空间 (Framed, R+W+U)
    │
    ├─ 5. 创建堆区域
    │    └─ 映射初始堆空间 (Framed, R+W+U)
    │
    ├─ 6. 映射 TrapContext
    │    └─ 用于保存/恢复上下文 (Framed, R+W)
    │
    └─ 返回 (MemorySet, user_sp, entry_point)
```

### 3. 地址翻译流程

```
CPU 访问虚拟地址
    │
    ▼
MMU 查询 TLB
    │
    ├─ 命中 → 直接获取物理地址 ✓
    │
    └─ 未命中 → 查询页表
         │
         ├─ 从 SATP 获取根页表地址
         │
         ├─ 三级页表查找：
         │   ├─ 一级页表 [VPN[2]]
         │   ├─ 二级页表 [VPN[1]]
         │   └─ 三级页表 [VPN[0]]
         │
         ├─ 检查 PTE.V 标志
         │   │
         │   ├─ 有效 → 获取 PPN
         │   │          更新 TLB
         │   │          返回物理地址 ✓
         │   │
         │   └─ 无效 → Page Fault
         │              触发异常
         │              内核处理
```

### 4. 进程切换

```
从进程 A 切换到进程 B
    │
    ├─ 1. 保存进程 A 的上下文
    │
    ├─ 2. 切换地址空间
    │    │
    │    └─ process_b.memory_set.activate()
    │        ├─ 写入 SATP = process_b.page_table.token()
    │        └─ sfence.vma (刷新 TLB)
    │
    ├─ 3. 恢复进程 B 的上下文
    │
    └─ 4. 返回用户态
         │
         └─ 进程 B 继续运行（使用自己的地址空间）
```

### 5. 资源回收（自动）

```
进程结束
    │
    ▼
MemorySet 被 drop
    │
    ├─ areas: Vec<MapArea> 被 drop
    │    │
    │    └─ 每个 MapArea 被 drop
    │         │
    │         └─ data_frames: BTreeMap 被 drop
    │              │
    │              └─ 每个 FrameTracker 被 drop
    │                   │
    │                   └─ Drop trait 触发
    │                        │
    │                        └─ frame_dealloc(ppn)
    │                             └─ 页帧回收到 recycled 栈 ✓
    │
    └─ page_table: PageTable 被 drop
         │
         └─ frames: Vec<FrameTracker> 被 drop
              │
              └─ 所有页表页帧自动回收 ✓
                  
完全自动化，无需手动释放！
```

## 设计模式

### 1. RAII (资源获取即初始化)

**FrameTracker 实现**：
```rust
{
    let frame = frame_alloc().unwrap();  // 获取资源
    // 使用 frame.ppn
}  // 离开作用域，自动释放
```

**优势**：
- 自动资源管理，防止内存泄漏
- 异常安全（即使 panic 也会回收）
- 代码简洁，无需显式释放

### 2. 类型安全

**强类型区分**：
```rust
VirtAddr ≠ PhysAddr      // 编译期保证不会混淆
VirtPageNum ≠ PhysPageNum
```

**优势**：
- 编译期捕获错误
- 自文档化
- 防止误用

### 3. 分层抽象

```
应用层 → MemorySet      (管理完整地址空间)
    ↓
中间层 → PageTable      (地址翻译机制)
    ↓
底层   → FrameAllocator (物理内存分配)
    ↓
基础   → Address        (类型系统)
```

**优势**：
- 职责清晰
- 易于理解和维护
- 可测试性强

### 4. 位标志 (Bitflags)

```rust
bitflags! {
    pub struct MapPermission: u8 {
        const R = 1 << 1;
        const W = 1 << 2;
        const X = 1 << 3;
        const U = 1 << 4;
    }
}

// 使用：
let perm = MapPermission::R | MapPermission::W;
if perm.contains(MapPermission::W) { ... }
```

**优势**：
- 紧凑存储
- 类型安全的位操作
- 清晰的语义

### 5. 懒初始化 (Lazy Static)

```rust
lazy_static! {
```

## 内存层次对比

### 堆分配器 vs 页帧分配器

| 特性 | 堆分配器 (heap_allocator.rs) | 页帧分配器 (frame_allocator.rs) |
|------|------------------------------|----------------------------------|
| **分配单位** | 字节级（任意大小） | 页级（4KB） |
| **用途** | 内核数据结构 (Vec, Box, String) | 页表、用户内存 |
| **算法** | 伙伴系统 (Buddy System) | 栈式分配 + 回收栈 |
| **空间来源** | HEAP_SPACE (固定大小) | 物理内存空闲区域 |
| **线程安全** | LockedHeap (互斥锁) | UPSafeCell (单核安全) |
| **可扩展** | 否（固定大小） | 是（取决于物理内存） |

### 恒等映射 vs 帧映射

| 特性 | 恒等映射 (Identical) | 帧映射 (Framed) |
|------|---------------------|-----------------|
| **VA vs PA** | VA == PA | VA != PA |
| **用途** | 内核空间 | 用户程序 |
| **灵活性** | 固定，不能移动 | 灵活，可任意映射 |
| **隔离性** | 无（共享物理地址） | 有（不同进程独立） |
| **典型场景** | 内核代码、设备寄存器 | 用户栈、堆、代码段 |

## 常见问题

### Q1: 为什么需要两个分配器？

**A**: 
- **堆分配器**：小对象，频繁分配/释放（Vec, Box）
- **页帧分配器**：大对象（4KB），用于页表和用户内存

### Q2: FrameTracker 为什么要清零？

**A**: 
- **安全性**：防止敏感数据泄露（如密码、密钥）
- **一致性**：保证新分配的页处于已知状态

### Q3: 为什么使用三级页表？

**A**: 
- **节省空间**：按需分配页表（一级页表只需 4KB）
- **支持大地址空间**：SV39 支持 512GB 虚拟地址空间
- **标准架构**：RISC-V SV39 规范

### Q4: KERNEL_SPACE 和用户进程的 MemorySet 有什么区别？

**A**: 
- **KERNEL_SPACE**: 恒等映射，全局共享，所有进程切换到内核态时使用
- **用户 MemorySet**: 帧映射，进程独立，提供地址隔离

### Q5: trampoline 是什么？

**A**: 
- **跳板页**：用于在用户态和内核态之间切换
- **特殊性**：在所有地址空间中映射到相同的虚拟地址
- **作用**：保证切换页表时代码仍然可执行
